# Инструкция для Claude: как подключить и вести Telegram-канал через бота

## Цель

Нужно настроить безопасную схему, при которой Claude/Codex/другой AI-агент может вести Telegram-канал: готовить посты, публиковать изображения, закреплять важные сообщения и вести контент-план.

Личный Telegram-аккаунт владельца использовать нельзя. Работать нужно только через Telegram-бота и Bot API.

Схема:

```text
Telegram-канал -> бот-админ -> Telegram Bot API -> AI-агент публикует контент
```

## Что нужно создать в Telegram

### 1. Канал

1. Открыть Telegram.
2. Создать новый канал.
3. Указать название, аватар и описание.
4. Сделать канал публичным, если нужен короткий адрес.

Пример:

```text
Название: Песня в подарок
Ссылка: https://t.me/V3SongCraft
```

### 2. Группа обсуждений

Группа нужна, чтобы под постами канала были комментарии.

1. Открыть настройки канала.
2. Найти раздел "Обсуждение".
3. Создать новую группу или привязать существующую.
4. Проверить, что под постами появляются комментарии.

### 3. Telegram-бот

Бот нужен для публикаций через API.

1. Открыть `@BotFather`.
2. Отправить:

```text
/newbot
```

3. Указать название бота.
4. Указать username, который заканчивается на `bot`.
5. Сохранить токен, который выдаст BotFather.

Токен выглядит примерно так:

```text
1234567890:AAHxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

Токен является секретом. Его нельзя публиковать в чатах, скриншотах, репозитории или открытых документах.

## Как выдать доступ боту

### Добавить бота в канал

Важно: бот должен быть администратором именно в канале, не только в группе обсуждений.

1. Открыть канал.
2. Нажать на название канала.
3. Открыть "Администраторы".
4. Нажать "Добавить администратора".
5. Найти созданного бота.
6. Дать права:

```text
Публиковать сообщения
Редактировать сообщения
Удалять сообщения
Закреплять сообщения
```

Минимально для публикаций достаточно права:

```text
Публиковать сообщения
```

Если бот не добавлен именно в канал, Telegram вернет ошибку:

```text
Forbidden: bot is not a member of the channel chat
```

### Добавить бота в группу обсуждений

Это нужно только если агент должен отвечать в комментариях или модерировать обсуждения.

Для обычной публикации постов в канал это не обязательно.

## Какие данные нужны агенту

AI-агенту нужны только:

```text
1. Bot Token
2. Chat ID канала
3. Контент-план
4. Правила тона и оформления
```

Для публичного канала обычно можно использовать username:

```env
TELEGRAM_CONTENT_CHAT_ID=@V3SongCraft
```

Для приватного канала или супергруппы нужен числовой `chat_id`, например:

```text
-1004364893295
```

## Где хранить токен

Токен нужно хранить в `.env`, а не в коде.

Пример переменных:

```env
TELEGRAM_CONTENT_BOT_TOKEN=PASTE_BOT_TOKEN_HERE
TELEGRAM_CONTENT_CHAT_ID=@V3SongCraft
```

Если проект на сервере лежит в `/opt/songcraft`, файл обычно здесь:

```text
/opt/songcraft/.env
```

После изменения `.env` нужно перезапустить приложение.

Пример:

```bash
cd /opt/songcraft
docker compose up -d app worker
```

## Как проверить подключение

### 1. Проверить бота

Вызвать метод Telegram Bot API:

```text
getMe
```

Успешный результат:

```json
{
  "ok": true,
  "result": {
    "username": "BotUsername"
  }
}
```

### 2. Проверить канал

Вызвать:

```text
getChat
```

Успешный результат:

```json
{
  "ok": true,
  "result": {
    "id": -1000000000000,
    "title": "Название канала",
    "type": "channel"
  }
}
```

### 3. Проверить публикацию

Публиковать нужно не тестовый мусор, а уже подготовленный пост, если владелец дал разрешение.

Методы:

```text
sendMessage
sendPhoto
```

Успешный результат:

```json
{
  "ok": true,
  "result": {
    "message_id": 4
  }
}
```

## Правила безопасности

Нельзя:

- использовать личный Telegram владельца;
- просить код входа в Telegram;
- просить QR-код Telegram Desktop;
- хранить Bot Token в коде;
- выводить токен в логах и финальных ответах;
- публиковать тестовые посты без разрешения;
- менять настройки канала без отдельной команды владельца.

Можно:

- публиковать через бота-админа;
- хранить токен в `.env`;
- использовать `@channel_username` или числовой `chat_id`;
- перевыпустить токен через BotFather, если он случайно попал в чат.

Если токен был скомпрометирован:

1. Открыть `@BotFather`.
2. Выбрать нужного бота.
3. Выбрать `API Token`.
4. Нажать `Revoke current token`.
5. Получить новый токен.
6. Заменить токен в `.env`.
7. Перезапустить приложение.

## Как агент должен готовить посты

Пост для Telegram должен быть оформлен под быстрый просмотр.

Правила:

- сильный первый абзац;
- короткие строки;
- один пост = одна мысль;
- без длинных полотен;
- без технических терминов;
- без лишних хэштегов;
- понятный CTA в конце;
- изображение должно усиливать идею поста;
- стиль должен совпадать с брендом канала.

Пример структуры:

```text
Сильный хук.

Короткое объяснение.

3-5 пунктов пользы или эмоции.

Мягкий CTA.
```

## Пример первого поста

```text
Песня в подарок - это не открытка.

Это момент, где человек слышит:
"это правда про меня".

Мы запустили канал SongCraft. Здесь будем показывать, как обычные истории превращаются в персональные треки: с именами, деталями, воспоминаниями и эмоциями.

Что будет в канале:
- реальные реакции людей;
- фрагменты готовых песен;
- разборы, как написать запрос, чтобы трек получился сильным;
- закулисье создания треков и клипов из фото.

Попробовать самому: @v3techtrackbot
```

## Что агент должен сообщить после публикации

После публикации агент должен дать короткий отчет:

```text
Опубликовано.
Канал: ...
Тип: пост с изображением
message_id: ...
```

Если публикация не удалась, агент должен указать точную ошибку Telegram API.

Примеры:

```text
Forbidden: bot is not a member of the channel chat
```

Значит бот не добавлен администратором именно в канал.

```text
Bad Request: chat not found
```

Значит неверный `chat_id` или бот не имеет доступа к каналу.

## Короткий чеклист

```text
[ ] Создан Telegram-канал
[ ] Создана группа обсуждений
[ ] Группа привязана к каналу
[ ] Создан бот через BotFather
[ ] Бот добавлен администратором в канал
[ ] У бота есть право публиковать сообщения
[ ] Bot Token лежит в .env
[ ] Chat ID указан в .env
[ ] Проверен getMe
[ ] Проверен getChat
[ ] Опубликован первый пост
```

## Итог

Безопасный доступ AI-агента к Telegram-каналу делается через бота-админа.

AI-агенту не нужен личный аккаунт владельца. Достаточно Bot Token, Chat ID и понятного контент-задания.
